# TRIPOD+AI statement: updated guidance for reporting clinical prediction models that use regression or machine learning methods

## Summary
The 2024 update of the TRIPOD reporting guideline for clinical prediction models. It replaces the 2015 checklist with a 27-item checklist that applies whether a model was built with regression or machine learning, plus a separate checklist for abstracts.

- Use it as the reporting checklist for the CARDIO-FM papers and for Marco's review.
